# Windows 维护脚本

把这几个文件放在同一目录，在要修复的 Windows 电脑上运行。请使用原本运行软件的 Windows 用户，右键 BAT 选择“以管理员身份运行”。软件和已有远程连接会暂时退出；请在本机操作。

- `Disable-Updates.bat`：关闭完整端与顾客版的后台自动升级、启动检查更新。修改当前用户配置和服务实际使用的 LocalService 配置；保留原来停止的服务状态。
- `Repair-Customer-Service.bat`：修复已安装顾客版的服务注册，清除停止服务选项，恢复本项目服务器地址、公钥与每次点击接受模式，为顾客版程序添加防火墙允许规则，并关闭更新、启动服务。仅处理通过内置标记识别的定制顾客版。
- `Windows-Maintenance.ps1`：两个 BAT 共用的实现，请与 BAT 放在一起。

每个被修改的配置文件会先在原目录生成 `*.before-maintenance-日期时间-随机值.bak` 备份。脚本只修改 `[options]` 中列出的选项，不删除设备 ID、密码、收藏和历史记录。运行中途报错时可能已应用部分选项，请保留屏幕上的错误和备份。

已更新成官方版时，请先重新安装原定制版本，再运行脚本。脚本不能把官方二进制变成顾客版，也不能恢复被覆盖的图标、快捷键处理和仅被控限制。

这两个脚本用于当前 Windows 安装，不能从旧二进制中删除手动更新按钮；不要再使用官方更新入口。源码补丁另外从定制构建中移除了更新入口，并拒绝更新查询与安装包下载，需要重新编译才会进入程序。

按用户要求，未运行这些脚本、启动测试或构建验证；由用户在 Windows 上试用。
